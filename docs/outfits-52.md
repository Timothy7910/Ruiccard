# 六張新增版本

鳴潮典藏目前共 52 張。新增今汐「桃夭灼灼」、長離原版、贊妮「城市午茶」、莫寧「呢絨夢」、琳奈「薄荷糖」、千咲「蜜桃冰」，保留既有版本。

人物與背景使用獨立圖層，坐姿的椅子、機車或泳圈隨人物保留。莫寧採用右側小人物，沒有將背景大肖像當作前景；莫寧與琳奈的背景另經清理，避免視差時出現重複人物。

沿用角色對應 TXT 代表詞與台詞、統一中文 112px 字級及右側英文、繁簡切換、完整卡框與一鍵 PNG 下載。新增十二張繁簡卡面均由實際 WebGL 展示匯出，目錄縮圖由完整卡面產生。

各卡片 sources 目錄包含分層素材、設定、提示詞來源紀錄及可編輯 card.blend。驗證結果位於 verification/outfits-52。
